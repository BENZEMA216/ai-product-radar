00:00 Muse 的历史

起点是 2025 年 6 月扎克伯格发的“个人超级智能”备忘录，Wang、Nat Friedman 等人参与。当时 agent 还没真正起来，备忘录只是隐约指向后来的 Muse。

前沿模型从头到尾的开发周期本身要很多个月：搭整套技术栈、做数据集、预训练、后训练。

今年年初 Opus 4.5 和 OpenClaw 让 agent 的潜力凸显。Nat Friedman 是 MSL 里第一个用 OpenClaw 的，体验“介于恐怖和狂喜之间”。他讲过一些故事，例如让 agent 盯着监控确保自己多喝水。

Wang 说 Nat 的判断很有分量（他是 Stripe 最早的客户之一，参与创建 GitHub Copilot）。随后两人每个空闲时间都在和各自的 OpenClaw 聊。

Wang 的第一个尝试：用 Nat 写的一个“全面心理剖析”提示词，多轮深度追问，agent 还能看他的邮件和照片。他形容这像“把三年心理治疗压缩到一次”，很脆弱的体验。

05:00 内部备忘录和原型

2 月，两人各写了备忘录并通过董事会渠道递上去。Wang 的观点：超级 agent 在某种意义上是消费产品的“终点”。Nat 写了两篇（标题大意是“责怪的是 Claude 而不是法律”“信任是必须的”），后来成为产品核心原则。

团队一两周内做出原型并向董事会演示。后来 Muse 的很多决定在第一版原型里已存在，比如吉祥物“Jolly 小人”和早期的 Muse 挂件。

从 2 月到 9 月发布的 7 个月，是把“偶尔神奇、大多数时候会崩”的原型变成高可靠消费产品的痛苦过程。

扎克伯格的角色：和大家一起体验“狂喜/恐怖”，用它管家里的事、陪孩子，也让它看自己练 MMA 的视频给建议。公司里开会会专门讲“你的 agent 干了什么疯狂的事”。

07:40 为什么 Muse 能做成而 OpenClaw 没有

Wang 表达了对 OpenClaw 作者 Peter Steinberger 的敬意，认为 OpenClaw 很有远见。

他认为 Muse 的“不光鲜”之处是把模型加产品的每个细节磨平，模型本身迭代了很多轮，路线图也瞄准个人超级智能和个人 agent。

背景：年初 Anthropic 在编程上遥遥领先，行业共识是“只有编程 agent 重要”，大家都挤过去。Meta 的信念是个人 agent，因为这是 Meta 独特的位置。

10:00 为什么个人 AI 适合 Meta

他对扎克伯格的第一个观点：AGI 的承诺是人少做“必须做的事”、多做“想做的事”，而 Meta 的产品（Instagram、WhatsApp、Facebook）恰好代表人们“想做的事”。

从传统看：连接人、帮人发现兴趣；从商业看：每天 35 亿人使用的分发。所以消费级和个人 AI 一直是 Meta 能做出特别东西的地方。

12:40 七个月怎么磨

模型路线把个人 agent 作为重点之一，有一张很长的表格，列了一百多项模型必须具备的具体行为和能力，每项都做了评测并专门训练，定期评审短板。

他说这延续了 Meta 的文化：知道衡量什么，就把每个细节优化好。以前是转化率、推荐率、引导流程，AI 时代是把模型磨到适配产品。

15:10–20:00 耐心与扎克伯格

主持人引用 Colossus 上 Jeremy Stern 写的扎克伯格长文：扎克伯格自称技能“不性感”，但擅长建团队、长期慢慢改进产品，也不会失去公司控制权、不需要再融资，所以能长期做下去。

Wang 称赞这 7 个月需要极大的耐心和克制。扎克伯格在财报电话会上其实一直暗示在做个人 agent，但公司内外有很多怀疑（“Meta 在烧钱”“扎克伯格赢不了 AI”）。

主持人转述文中的说法：有竞争对手说“Mark 是终结者”，不会停。Wang 补充：个人 agent 这个品类处在刀刃上，可靠就可能是史上最好的消费产品之一，不可靠用户就说是垃圾。

20:00 可靠性与上线标准

做了很多轮“新用户从零下载使用”的测试。Muse 的前提是“不是聊天机器人，是 agent”，对普通用户需要精心引导。AB 测试显示产品体验对模型质量非常敏感，包括任务可靠性、沟通质量、该问用户时会不会问。

上线判断部分是数字化的：那张表里每一行都设了“阻塞发布的阈值”和“合格阈值”。很多检查点 80% 项绿、20% 项红，不行。第一个全绿的检查点是经过专门训练的 Muse Spark 1.3 版本。同时也有主观感受：明显比之前强。

22:40 团队规模与“一件作品”

模型加产品总共不到 200 人。高层都知道这是 Meta 今年最重要的产品之一，但组织上克制住了没让它膨胀。

他说大公司产品常变成“各人观点缝合怪”（每个 PM 都往里塞东西，最后像一杯奶昔），用户能感觉到。Muse 必须有单一的观点和统一的体验。

主持人拿乔布斯类比（“苹果是有一万条命的乔布斯”）。Wang 说 Nat Friedman 的品味和判断塑造了产品。

25:00 用户数和 X 上的“疯癫”发帖

官方只说“数百万”，Wang 转发过一些图暗示它是史上增长最快的消费级 AI 应用。他没给具体数字。

他发帖风格在发布后变得很“疯”。原因：一是要让 Muse 突破每天被新模型新产品轰炸的噪音；二是想让 Meta 重新变酷；三是一些推文意外火了，他重新意识到“互联网奖励冒险和意外”。

他提到有一群“整天想梗”的朋友。他自己有时开会想到梗要立刻发。Nat 在会上开玩笑说，“我们本来以为能了解 Muse 用户，结果了解的是 Alex 的大脑”。他认为这确实对增长有帮助，但没有追踪数据。

30:30 让产品出圈、留住人

想法：尽快让用户到达“哇”的时刻；把用户的惊叹故事用起来。他最初主要是转发几十个用户用例。

吐槽 Anthropic 和 OpenAI 的广告：不直接展示产品能为用户做什么。他引用早期广告经典《Scientific Advertising》（Hopkins）的核心观点：人们只关心自己，广告要从“对你有什么用”出发。

吉祥物的作用：他有一次开车去上班，让 Muse 生成吉祥物提着公文包，配文“周一上班的我”，发现这个形象可以放进各种场景，有传播力。

留存：像“信任跌落”，先给 agent 小任务，成功后给更大的。成功用户就是被带着给越来越大的任务，而每次都做成。

36:00 口碑和截图传播

主持人说真正让他下载的是一个朋友发来的截图：朋友把证件落在了私人飞机上，对 Muse 说“我完全不想参与，你想办法”，Muse 一路安排快递员、进入大楼送到办公室。

Wang 认为现代消费产品必须“在截图里能传播”，而截图里有吉祥物，立刻让人认出这是 Muse，是最好的营销。

他自己的用法：设了很多工作流，把它当“第二大脑”，开会时放心。

39:00–45:00 “第二个大脑”与“人人都有主体性”

他写的短文（据说有约 550 万浏览）把 Muse 说成“每个人在自己大脑之外的第二个大脑”。他认为个人 agent 会是长期形态：人的天性是有欲望和梦想，AI 是实现它们的桥，人会梦想得越来越大。

他说 Muse 能“给每个人童年时梦想的成年生活”。孩子有大梦想，长大后被学业和职场磨掉，“变成僵尸”。AI 可以让主体性像扶梯一样随年龄上升，而不是被压垮。

他引用最成功的创业者的模式：梦想大，实现，再梦想更大。这应该对每个人成立。

他设想每个人的主体性都被打开后，世界会很多元、很怪、很艺术，“像 Rick and Morty 的跨维度有线电视变成现实”。

45:20 Meta 与 Scale AI 的交易

起因：Alex Schultz（Meta 首席数据官）大约在 2021–2022 年把他介绍给扎克伯格。从介绍到第一次见面花了约一年，因为扎克伯格极度优先排序。之后大约半年联系一次，Wang 向他请教创业问题，会在 WhatsApp 上收到很长的认真回复。Meta 是 Scale 的重要客户。

Llama 4 之后，扎克伯格打电话问“你觉得我们该做什么”。从第一次聊到宣布交易大约五六周。

Wang 起初觉得不合理：Instagram、WhatsApp 的收购有明确产品逻辑，Scale 是企业和政府的数据业务。后来才明白，扎克伯格主要想要人才并重启 AI 项目。他开玩笑说“钱到账、谈到数字之后”才变清楚。

交易结构：Meta 持有 Scale 49%，Scale 继续运营，Wang 和少数人加入 Meta。他认为对 Scale 的所有股东、对公司和对他都是三赢。他说放下干了 9 年、视为毕生事业的公司，情感上很难。

最后让他决定的：三方共赢，以及他看到 Meta 的潜力。当时 Meta 的 AI“像受损品”，这反而激发了他的创业者一面：可以从头搭团队、原则和文化。

55:00 重启实验室的原则

小而扁平、技术很强的团队，高人才密度，能多快动起来。他说这是和扎克伯格最早聊的重点。

主持人用《拿破仑的思想》类比：先充分思考，一旦决定就全力投入（“把弹夹打空”）。Wang 认为扎克伯格已经内化“失败不重要，赢的时候赢多大才重要”，所以能在很多情况下毫无畏惧。他引用扎克伯格那句“在快速变化的世界里，最大的风险是不冒险”。

如果不是这样，Meta 可能更像谷歌：更慢更官僚。

58:00 从 Scale 创始人到 MSL 的管理方式

在 Scale：他信奉“创始人要能干每一个岗位”，公司是他观点的产物，也让他成了瓶颈。他认为第一次创业应该这样。

在 Meta：没有条件“每个岗位都自己做”（他不是研究员也不是产品设计师），所以第一要务是招到各领域顶尖的人，再创造让他们发挥最好的环境，像教练。

MSL 的吸引力：从头搭实验室、小团队、有清晰方向（个人超级智能）、不被算力、基础设施、分发卡住。他说很多人希望 AI 对自己的妈妈、奶奶都有意义。

薪酬：OpenAI 和 Anthropic 的股价大涨，所以对很多人来说是“大致持平”。

62:50 “钻石矿” vs “盖摩天楼”

他的角色：设定北极星（个人超级智能，赢下消费 AI，做对每个人有意义的 AI），发现特殊人才，给环境和资源。大公司常见错误是不放权，人才就走了。

研究本质上是探索未知，需要时间和空间，大部分想法不会成，少数成功的足以覆盖投入。

比喻：有些工作像“钻石矿”（幂律回报，风险投资是典型，Meta 实验室像这样），有些像“盖摩天楼”（回报线性，靠运营效率，数据标注和亚马逊 Prime 配送类似，他在 Scale 做的就是这种）。

65:30 他 19 岁生日聚会的故事

他 19 岁在 MIT 读大一，冬季在交易公司 HRT 实习，大约 10 到 12 个实习生，多数来自哈佛和 MIT，不少是竞赛认识的。其中后来创办了 Hyperliquid（Jeffrey Yan）、Cognition（Scott Wu）、Decagon（Jesse Zhang），还有一位在 Anthropic 做研究的 Vicky Yu（字幕写作 “Vicky Yei”，拼写待核实）。

他说 HRT 现在很赚钱（字幕里说某季度营收 110 亿美元、利润 80 亿美元，字幕可能有误，数字待核实），开玩笑说“给实习生都投种子轮”。

68:00 为什么有 200 多个直接下属

MSL 的设计原则：高人才密度、技术导向、反官僚。TBD 实验室的研究员都直接向他汇报，超过 200 人。

技术方向由各“小组”（pod）的技术负责人拍板，群体决策靠辩论。他说自己“不是最好的管理者”，但这些人不需要管理，需要好环境和“自由发挥的空间”。主持人总结：更像“好环境的看护者”。

一句话看点

Muse 从 2 月的原型到 9 月发布，核心是一张百余项能力清单加严格门槛，团队不到 200 人、保持单一产品观点；Wang 把它定位成“人人的第二个大脑”，并详细讲了他加入 Meta 的经过和 MSL 的管理哲学。
